[経済データスクエア](https://econ.aidotters.com)は、世界銀行や日本の各省庁が公表している経済統計を1か所に集めたサイトです。指標を探して選ぶと、そのままグラフになります。

無料で、ログインなしで使えます。この記事では、実際に1枚のグラフを作って資料に貼るまでの流れを説明します。

## まず1枚作ってみる

画面の上部に検索欄があります。ここに指標名や国名を入れると、全ソースを横断して候補が出ます。

```
消費者物価指数
失業率
GDP
為替
```

日本語で入れて構いません。世界銀行のデータは元の指標名が英語ですが、表示は日本語に揃えてあります。

![横断検索に「消費者物価」と入力した状態。e-Stat の消費者物価指数（総合・地方別）と World Bank のインフレ率が、ソース名のバッジ付きで候補に並んでいる](./economic-data-square-how-to-search.webp)

候補から系列を選ぶと、チャートスタジオが開いてグラフが描かれます。ここまでで、統計サイトを探してExcelをダウンロードして整形する、という手順は要りません。

## 4つの画面の使い分け

目的によって入口が違います。

### 世界経済ダッシュボード（`/`）

世界銀行のマクロ指標を主要国で比べる画面です。表示は3つ切り替えられます。

- **カード** — 指標ごとに最新値と前年比を並べる
- **マトリクス** — 国×指標の表。値の大小で色がつく
- **多国比較チャート** — 複数国の同じ指標を1枚に重ねる

![世界経済ダッシュボードのカード表示。カード／マトリクス／多国比較チャートの切り替えタブの下に、指標と国の絞り込みチップが並び、実質GDP成長率のカードが国ごとに最新値・前年差・スパークラインつきで格子状に表示されている](./economic-data-square-how-to-world.webp)

「日本の物価上昇率は他国と比べてどうか」のような問いは、ここが速いです。

### 日本経済ダッシュボード（`/japan`）

e-Stat（政府統計の総合窓口）・日本銀行・財務省・内閣府など、日本の公的統計をまとめて見る画面です。世界経済ダッシュボードが国際比較なのに対して、こちらは国内の統計を細かく見るためのものです。

### 国別プロファイル（`/country/JPN` など）

1つの国について、共通の11指標を並べた画面です。それぞれにG20内の順位がつきます。

![日本の国別プロファイル。自動生成の概況文の下に、実質GDP成長率・名目GDP・一人当たりGDPなどのカードが並び、それぞれに「高い順 12/19位」のようなG20内順位バッジがついている](./economic-data-square-how-to-country.webp)

「この国の経済の全体像をざっと掴みたい」ときに向いています。国名で検索するか、世界経済ダッシュボードの国名から移動できます。

### チャートスタジオ（`/studio`）

自分でグラフを組み立てる画面です。作りたい図の形を最初に選びます（あとから切り替えられます）。

- **時系列推移** — 時間に沿った動き。複数系列を重ね、前年比・指数化・寄与度分解ができる
- **散布図** — 2つの指標の関係。各時点を点にして時間順に結ぶ（連結散布図）
- **ランキング** — 系列グループを1つ選び、中の全系列を値で並べる
- **プリセット** — 定型チャートの一覧。開くとすでに絵ができている

![チャートスタジオの入口。時系列推移・散布図・ランキング・プリセットの4枚のカードが並び、それぞれに説明と使えるデータの範囲が書かれている](./economic-data-square-how-to-studio.webp)

**どれを選べばいいか分からないときはプリセットから見てください。** イールドカーブ、人口ピラミッド、内訳、国際比較の断面など13種あり、開いた状態から系列を差し替えていくほうが、白紙から組むより早いことが多いです。

## よく使う操作

![プリセットカタログ。国際比較・金融/為替・経済全体・生産/設備投資・貿易・人口/観光/消費の6セクションに、イールドカーブや寄与度分解などの定型チャートが説明つきで並んでいる](./economic-data-square-how-to-presets.webp)

### 前年比・指数化に切り替える

水準（そのままの値）で見ると比較しづらい指標があります。金額の単位が違う国どうしを比べるときや、規模の差が大きすぎるときです。

時系列推移では、**前年比**や**指数化**（ある時点を100とする）に切り替えられます。単位の違う系列を1枚に重ねたいときは指数化が使えます。

### 複数の系列を重ねる

左側のパネルから系列を選ぶと、同じグラフに追加されます。ソースをまたいでも構いません。日本銀行の金利と総務省の物価を1枚に重ねる、といったことができます。

系列が増えて探しづらくなったら、上部の絞り込みでソースや頻度（月次・四半期・年次）を限定できます。

### 上昇・下落の色を変える

ヘッダーに「上昇/下落の色」の設定があります。赤と緑の組み合わせは色覚特性によって見分けにくいことがあるため、別の配色に切り替えられるようにしてあります。資料の配色に合わせたいときにも使えます。

## 資料に貼る

グラフができたら、ツールバーの **「PNG 書き出し」** で画像として保存できます。

書き出した画像には、**タイトル・出典・データ時点が焼き込まれます**。これは意図的な仕様です。グラフだけを切り出して貼ると、あとから「これは何のデータだったか」「いつ時点か」が分からなくなり、出典表示の要件も満たせなくなるためです。

![チャート下部の表示。データ時点と、出典・ライセンス・加工の旨が本文として表示され、その下に配色・表示設定・PNG 書き出しのボタンが並んでいる](./economic-data-square-how-to-export.webp)

書き出しサイズは選べます。スライドに貼るか、ドキュメントに貼るかで使い分けてください。

## URLで共有する

チャートスタジオの**編集状態はURLに入ります**。系列の選択・変換・タイトルまで含まれるので、URLをコピーして渡せば、相手も同じグラフを開けます。

「この数字どこから来てるの」と聞かれたときに、画像ではなくURLを送れば、相手が自分で確かめられます。

## データを読むときの注意

### データ時点を見る

グラフには「データ時点」が表示されます。統計の公表間隔は日次・週次・月次・四半期・年次と統計ごとに違うため、**最新の点がいつなのかは統計によって違います**。

サイト自体は毎朝9:30に各出典から取り直していますが、それは「取りに行った時刻」であって「統計が更新された時刻」ではありません。

### 出典とライセンスを確認する

`/about` に、収録している統計の出典と利用条件の一覧があります。統計ごとに条件が違うため、機関単位ではなく統計単位で並べてあります。

資料に使う前に、その統計の条件を確認してください。商用利用が認められていないものは収録していませんが、出典表示が必要なものはあります。

### 数値が変わることがある

経済統計は、あとから改定されます。速報値が確報値に置き換わるのは正常な運用です。同じ指標を別の日に見て値が違っていた場合、まず改定を疑ってください。

## いま使えないもの

正直に書いておきます。

- **REST API と MCP** — 実装はしていますが、有料プランでの提供予定で、現在は開放していません。開始時期は未定です
- **マイダッシュボード**（チャートを保存してボードに並べる） — 有料化後の提供予定です

現在無料で使えるのは、**探す・グラフにする・PNGで書き出す・URLで共有する**までです。
